# Fotografías del sitio

Las diez imágenes se generaron en Canva (cuenta del propietario, 8-nov-2026).
Se exportaron desde Canva (diseño «Lienzo horizontal para fotografías») y ya
están enlazadas en `src/content/site.ts`. Nombres y contenido:

| Archivo | Imagen |
|---|---|
| `hero.jpg` | Planta de producción al amanecer, ingeniero de espaldas |
| `soluciones/estrategia.jpg` | Manos revisando un diagrama de procesos sobre la mesa |
| `soluciones/automatizacion.jpg` | Supervisor con tableta en bodega |
| `soluciones/datos.jpg` | Sala de reuniones con tablero proyectado |
| `soluciones/soluciones-digitales.jpg` | Dos personas revisando una herramienta en un portátil |
| `soluciones/sistemas-inteligentes.jpg` | Manómetro análogo con cámara industrial |
| `sectores/manufactura.jpg` | Operaria en línea de empaque (vertical) |
| `sectores/transporte.jpg` | Patio de camiones al amanecer (vertical) |
| `sectores/servicios.jpg` | Recepción de clínica (vertical) |
| `sectores/publico.jpg` | Ventanilla de atención al ciudadano (vertical) |

Para reemplazar una foto basta con sobrescribir el archivo con el mismo nombre
y medidas. Si se quita el campo `image` de una entrada, la tarjeta vuelve a su
lámina dibujada (`src/components/laminas.tsx`).
